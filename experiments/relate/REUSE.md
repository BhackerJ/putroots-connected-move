# Put Roots reuse

The existing Put Roots rules card renderer and its CSS were extracted from
`src/map-agent.ts` in the Put Roots repository (baseline e17566c).
The product map and the demo import that shared module.

The Relate graph, synthetic source material, scheduling queries, example
server, comparison interface and Claude tool bridge are contest work.
Claude Code and Codex assisted development. Claude Code is also the optional
live agent runtime and Relate 1.0.1 is the graph engine.
